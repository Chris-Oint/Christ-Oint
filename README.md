# WMB — Bible d’étude

**WMB** (en haut) · **Bible d’étude** (en dessous)

Application web progressive (PWA), réalisée à partir du fichier HTML fourni et utilisant la photo remise par l’utilisateur comme icône et logo d’application.

## Utilisation en ligne et hors ligne

1. Ouvrir [WMB Bible d’étude](https://chris-oint.github.io/Christ-Oint/) une première fois avec une connexion Internet.
2. Laisser l’onglet ouvert jusqu’à la fin du premier chargement. L’application met en cache sa page, son icône et les cinq jeux de données de brochures (environ 51 Mo de fichiers compressés).
3. Installer l’application depuis le menu du navigateur : **Installer l’application** dans Chrome/Edge, ou **Partager → Sur l’écran d’accueil** dans Safari sur iPhone/iPad.
4. Après cette préparation initiale, l’application et les données locales sont disponibles hors ligne. Les fonctions qui ouvrent un site externe nécessitent toujours une connexion.

Les notes, soulignements et préférences restent enregistrés sur l’appareil dans le stockage local du navigateur; ils ne sont pas synchronisés entre appareils.
